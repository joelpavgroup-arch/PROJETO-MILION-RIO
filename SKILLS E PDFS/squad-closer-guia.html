Passo 03
HABILITAR AS SKILLS NA CLAUDE

Antes de subir os agentes, você precisa ativar duas funções nas configurações.

1
Abra as Configurações

Clique no seu nome ou foto de perfil no canto inferior esquerdo da tela.

Selecione Settings (Configurações).

2
Ative o Code Execution

Vá em: Feature Previews

Settings › Feature Previews › Code Execution and File Creation

Ative o botão. Isso é obrigatório — as Skills não funcionam sem essa opção.

3
Ative as Skills

Ainda em Feature Previews, ative também:

Settings › Feature Previews › Skills

Após ativar os dois, as Skills já estarão disponíveis na sua conta.

Passo 04

Você recebeu 9 arquivos .skill — um para cada agente. Siga os passos abaixo para instalar cada um.

1
Acesse a área de Skills
Settings › Customize › Skills

2
Faça o upload de cada agente

Clique em Upload Skill

Selecione o primeiro arquivo .skill da sua pasta do SQUAD CLOSER.

Repita o processo para cada um dos 9 agentes.

Ordem não importa. Você pode subir em qualquer ordem. Cada agente funciona de forma independente.
3
Confirme que todos estão ativos

Após o upload, cada agente vai aparecer na lista com nome e descrição.

Certifique-se de que todos os 9 estão listados e com o toggle ativado.

Passo 05
COMO USAR OS AGENTES

Simples. Você abre a Claude, escreve o que precisa e o agente certo entra em ação automaticamente.

1
Abra uma nova conversa na Claude

Acesse claude.ai e clique em New Chat.

As Skills ficam ativas em segundo plano — você não precisa ativar nada a cada conversa.

2
Fale com o agente que você precisa

Você pode chamar diretamente pelo nome ou descrever sua situação. Exemplos:

→ Para prospectar leads: "SCOUT, inicia. Quero encontrar clientes para minha consultoria de marketing."
→ Para abordar um lead frio: "Preciso de um script de primeiro contato para abordar no WhatsApp. Lead é nutricionista e não me conhece."
→ Para quebrar uma objeção: "O lead disse que é caro. Como respondo?"
→ Para recuperar um lead que sumiu: "Lead estava interessado, recebeu o preço e sumiu há 10 dias. Como reativo?"
→ Para analisar suas vendas: "ANALYST, inicia. Quero entender onde meu funil está travando."
3
Responda as perguntas do agente

Cada agente vai fazer perguntas estratégicas sobre seu contexto — uma por vez.

Quanto mais detalhado você for nas respostas, mais preciso será o script ou a análise entregue.

4
Receba e aplique o protocolo

O agente entrega o script pronto, o protocolo ou a análise — formatado para uso imediato.

Copie, adapte com seu nome e aplique direto no WhatsApp, DM ou call.

Dica: Guarde os scripts que mais funcionam. Com o tempo você vai ter um banco de mensagens validadas para cada situação do seu processo de vendas.
